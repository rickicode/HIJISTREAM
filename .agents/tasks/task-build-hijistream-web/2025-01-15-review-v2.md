# HIJISTREAM web app — post-fix review (v2)

All nine issues from the v1 review have been addressed. The CSP meta tag is present, postMessage validates origin, Continue Watching stores metadata, EpisodeList accepts real episode data, dead stores are removed from components, cache coordination uses `staleTime: 0` with CacheManager as sole persistence, and search items carry `_detectedType`. The app is in shippable shape with two minor residual items.

**Watch for:** Zustand remains as a dependency and in the Vite chunk-splitting config despite all store files and imports being removed (confirmed). The CSP `style-src` directive does not include `https://fonts.googleapis.com`, which will block the Google Fonts CSS import in browsers that enforce CSP strictly (confirmed).

## High-level view

The CSP is comprehensive — covering images, frames, scripts, fonts, and connect-src for the API — but `style-src` omits `fonts.googleapis.com`, meaning the Inter font stylesheet will be blocked under strict enforcement. This is the one remaining security gap.

Zustand was removed from all source files but left behind in `package.json` and Vite's `manualChunks` config. The build will bundle ~3KB of unused library code. A cleanup of both files resolves this.

## Orphaned Zustand dependency

The store files (`contentStore.js`, `playerStore.js`) were deleted and no component imports Zustand, but `package.json` still lists `"zustand": "^4.5.2"` and `vite.config.js` includes it in the `manualChunks.state` array:

```javascript
manualChunks: {
  vendor: ['react', 'react-dom', 'react-router-dom'],
  state: ['zustand', '@tanstack/react-query'],
},
```

This causes Vite to bundle Zustand into the `state` chunk even though nothing imports it. The fix is to remove `zustand` from both `package.json` and the `manualChunks` config (rename the chunk to just `['@tanstack/react-query']` or fold it into vendor).

## CSP style-src gap for Google Fonts

The CSP meta tag includes `font-src 'self' https://fonts.gstatic.com` (correctly allowing font file downloads), but `style-src` is only `'self' 'unsafe-inline'`. The page loads a stylesheet via:

```html
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap" rel="stylesheet" />
```

Under strict CSP enforcement, this external stylesheet load is blocked because `fonts.googleapis.com` is not in `style-src`. The fix:

```
style-src 'self' 'unsafe-inline' https://fonts.googleapis.com;
```

Alternatively, self-host the Inter font to eliminate the external dependency entirely.

## Resolution of v1 issues — confirmed

1. **CSP meta tag** — Present in `index.html` with `default-src`, `img-src`, `frame-src`, `script-src`, `style-src`, `connect-src`, `font-src` directives.
2. **postMessage origin validation** — `VideoPlayer.jsx`: `if (event.origin !== 'https://vaplayer.ru') return;`
3. **Continue Watching metadata** — `saveWatchProgress` accepts `metadata` param and persists `title`, `poster_url`, `type`. Home reads these fields for card rendering.
4. **EpisodeList data-driven** — Accepts `episodes` prop, filters by season, falls back to generated list only when no data provided.
5. **Dead contentStore** — File removed, no imports remain.
6. **Dead playerStore** — File removed, no imports remain.
7. **Double caching** — `staleTime: 0` means React Query never serves stale in-memory data; CacheManager is sole persistence. Clear Cache calls `queryClient.clear()`.
8. **Search type detection** — `_detectedType` field added per item in Search.jsx; ContentCard uses it for link href.
9. **Keyboard shortcuts** — Scope clarified to Escape (global back) and F (fullscreen in Player). Cross-origin iframe control acknowledged as infeasible.
